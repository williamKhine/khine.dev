# Triage labels

Use the canonical role as the GitHub label name.

| Label | Meaning |
| --- | --- |
| `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | The issue is waiting for more information. |
| `ready-for-agent` | The issue is ready for agent implementation. |
| `ready-for-human` | The issue requires human implementation. |
| `wontfix` | The maintainers have declined the issue. |
