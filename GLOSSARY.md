# Developer Portfolio

William Khine’s public portfolio helps recruiters and engineering hiring managers evaluate his work as a full-stack developer.

## Language

**Project**

A piece of work William contributed to that he can discuss publicly. Its source code or live demo may be private.

**Case Study**

A public write-up of a Project that explains the problem, William’s contribution, a technical trade-off, and the outcome or what remains unmeasured.

**Résumé Version**

A tailored PDF of William’s résumé prepared for one job application.

**Archived Résumé Version**

A Résumé Version retired from new sharing. Its existing valid Résumé Codes still grant access.

**Résumé Code**

A case-sensitive, six-character hexadecimal code in a portfolio link that grants anyone holding a valid copy access to one specific Résumé Version. Revocation ends access through that code.
